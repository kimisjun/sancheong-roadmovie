# RIVER TO SCREEN

2026년 7월 18일 사천 출발 산청 경호강 래프팅·진주·사천 당일치기 여행 페이지입니다.

## 두 가지 엔딩

- CUT A: 진주혁신 롯데몰 → 19:25 모아나
- CUT B: 사천 바다 드라이브·블루샥 → 22:00 모아나

## 실행

```bash
python3 -m http.server 8765
```

브라우저에서 `http://localhost:8765`로 접속합니다.

## 기술

- 순수 HTML/CSS/JavaScript
- 선택한 엔딩과 준비물 체크는 해당 브라우저의 localStorage에만 저장
- GitHub Pages 배포용 상대 경로
- 기존 `gyeongju-roadmovie`의 시네마틱 디자인·타임라인·카운트다운·공유·체크리스트 구조를 재사용

## 주의

날씨, 래프팅 운항, 매장 영업시간, 영화 상영시간은 출발 직전에 공식 채널에서 다시 확인해야 합니다.
